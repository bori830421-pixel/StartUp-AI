# 原型四：卖技能与服务

## 定义

用专业能力换钱，靠口碑复购，人力是瓶颈。

常见：家政保洁、上门维修、摄影、设计、代运营、家教、宠物上门服务、健身私教。

## 收入公式

```text
收入 = 单量 × 单价，单量受人力上限约束
```

和卖时间的区别：卖时间卖的是「在场」，卖技能卖的是「产出」。所以单价可以高很多，但同样受人力限制。

## 成本结构

| 成本项 | 刚性 | 说明 |
| --- | --- | --- |
| 货款 | 极低 | 多数无实物，或有少量耗材 |
| 获客成本 | 高 | 首单往往不赚钱，靠复购摊薄 |
| 工具与耗材 | 低 | 可预测 |
| 交通 | 中 | 上门服务尤其明显 |
| 赔付与返工 | 隐性 | 一次投诉可能吃掉数单利润 |

几乎没有刚性成本，这是它最大的优势。所以它的失败很少因为「钱不够」，多数因为「没人来」。

## 现金流节奏

好。服务完成即收款，无库存无账期。

## 天花板在哪

中等，受人力限制。突破只有两条路：

1. **提价**：靠专业度和口碑，空间有限但可控
2. **标准化加雇人**：从「自己干」变成「管别人干」，但那已经是另一个原型

## 关键约束

**获客与口碑的循环。** 没有口碑就没有单，没有单就留不住人。这是一个先有鸡还是先有蛋的问题，比选址更难破。

## 常见死法

| 死法 | 前兆 |
| --- | --- |
| 低价获客不赚钱 | 首单亏损，指望复购，但复购率没算过 |
| 品质不稳导致口碑崩 | 同一个客户两次体验差异大 |
| 客户跳单 | 客户直接联系服务者，绕过你 |
| 创始人即瓶颈 | 所有单都要自己上手，一停就断收入 |
| 会干活不等于会做生意 | 手艺好但不会获客与定价 |

## 劝退条件

严格说没有「不该做」的情形，但有两种错配要指出：

1. **只会干活，不愿获客** —— 这个原型的核心动作是获客，不是交付
2. **指望靠手艺做到很大** —— 不转成管人或标准化，天花板就是自己的工时

## 体检要点

| 维度 | 调整 |
| --- | --- |
| H1 客户可达 | 最容易通过的一类。能列出 10 个具体小区、渠道方或转介绍来源即可 |
| H2 现金流断点 | 现金流好。要把「首单不赚钱」计入，可撑月数覆盖 3 到 5 单的获客亏损 |
| H3 合规前置 | 门槛低，但母婴、养老、医疗相关需要资质 |
| S1 资金匹配 | 门槛最低的一类 |
| S2 时间匹配 | 注意体力上限与上门路程 |
| S3 能力缺口 | **关键动作是获客和定价，不是干活**。这是最常见的错配 |
| S4 失败可逆性 | 工具可转卖，无装修，通常 3 分 |

## 定向检索清单

1. **同类服务的当地市场价**（假装客户打 5 家电话问价，同时问排期）
2. **该服务的资质要求**（母婴、养老、医疗相关必须查）
3. **用工模式的法律责任**（员工制与中介制完全不同）
4. **平台抽成与结算规则**（如通过平台接单）

第 1 项不能靠检索，一个下午打电话就能做完，比任何报告都准。

## 判断这句话

> 这个原型的门槛不在手艺，在获客。会干活的人很多，能把活卖出去的人很少。
