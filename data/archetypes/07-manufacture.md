# 原型七：生产制造

## 定义

投入设备与产能，接单生产。收入靠产能利用率，风险靠订单和资金。

常见：小工厂、小作坊、代加工、食品加工、五金加工、服装加工。

## 收入公式

```text
收入 = 产能 × 单价 × 产能利用率
```

三个变量里，**产能利用率**是最容易被高估的。设备买回来不等于能跑满，多数小厂长期在 30% 到 50% 之间。

## 成本结构

| 成本项 | 刚性 | 说明 |
| --- | --- | --- |
| 设备 | 极高 | 大额，专用设备几乎无法转卖 |
| 厂房租金 | 高 | 合同期锁定 |
| 人工 | 高 | 技术工种难招难留 |
| 原料 | 中 | 随单量 |
| 环保与安全投入 | 高 | 常被忽略，但可能决定能否开工 |
| 资质与认证 | 高 | 生产许可、环评、消防 |

刚性最强的是设备——它同时是最大投入和最难回收的部分。

## 现金流节奏

**七种原型里最差。** B 端账期通常月结 30 到 90 天，且需要垫资买原料、发工资。

这意味着：有订单也可能因为没钱垫资而做不了。这是制造业最典型的死法。

## 天花板在哪

高，但门槛也高。真正的天花板是「订单稳定性」和「资金周转能力」，不是产能。

## 关键约束

**订单 + 资质 + 垫资能力，三者缺一不可。**

## 常见死法

| 死法 | 前兆 |
| --- | --- |
| 订单不足，产能闲置 | 设备买回来，产能利用率长期低于 50% |
| 账期拖死现金流 | 客户月结 90 天，但原料要现结、工资要月发 |
| 环保或安全不达标被停 | 开工前没做环评，或没做消防验收 |
| 大客户依赖 | 单一客户占营收 50% 以上 |
| 设备专用无法转卖 | 设备只能做一种产品，行业变化即报废 |

## 劝退条件

个体创业出现任一条，明确说不建议：

1. **启动资金 < 设备 + 6 个月固定成本 + 3 个月账期垫资**
2. **没有稳定订单来源**（「先建厂再找订单」是最危险的顺序）
3. **没有相关行业经验**（制造业的经验门槛远高于服务业）
4. **产品需要专门资质而你没办**

## 替代路径

不建议直接建厂，不等于不能做这个生意。三条更轻的路径：

| 路径 | 说明 | 风险 |
| --- | --- | --- |
| 先做贸易 | 接单后委托工厂生产，赚差价 | 利润薄，但零设备投入 |
| 委托加工（OEM） | 自己负责品牌与销售，生产外包 | 品控依赖工厂 |
| 先做代工 | 给现有工厂做外协，用别人的设备 | 受制于人，但零投入验证 |

正确顺序是：**先接单 → 再找产能 → 最后才考虑自建**。反过来做，就是拿全部资金赌一个没验证过的订单。

## 体检要点

| 维度 | 调整 |
| --- | --- |
| H1 客户可达 | 转成「订单可达」：能否列出 10 个具体潜在客户（公司名、采购负责人、年采购量）；**其中至少 3 个要说清采购周期**——下次什么时候采购、单次量多少、现在从谁家进 |
| H2 现金流断点 | **必须算账期**。可撑月数要覆盖「原料垫资 + 工资 + 账期」三项叠加 |
| H3 合规前置 | 最容易卡这里：生产许可、环评、消防、特种设备 |
| S1 资金匹配 | 门槛最高的一类 |
| S2 时间匹配 | 制造业是全天候，不是兼职能做的 |
| S3 能力缺口 | 关键动作：订单获取、生产管理、品质控制、供应链、资金调度 |
| S4 失败可逆性 | 通常 0 到 1 分。专用设备几乎无法转卖 |

**为什么要问采购周期。** 制造业的客户不是「认识就够」：采购有预算周期，换供应商有切换成本。报得出公司名和负责人，只说明你查到了名录；3 个说清采购周期，才说明你摸到了真实的采购节奏，而不是「他们应该需要」。说不清判信息不足，补测动作是「问这 3 家下一次采购在什么时候、现在从哪家进、什么情况下会换」，一周内能问完。

**与 H2 的分界。** H1 只判「订单入口在不在」，账期与垫资撑不撑得住归 H2。两者混判会把「有客户但没钱垫资」误判成「没客户」，给出错的补测动作——该去谈账期，却让人回去补客户名单。

## 定向检索清单

1. **产品是否需要生产许可**（工业产品生产许可证目录、食品生产许可等）
2. **环评要求**（是否需环评审批或备案，园区是否有准入限制）
3. **厂房的消防与安全要求**
4. **同类工厂的实际产能利用率与账期**（问同行，不问设备商）

## 判断这句话

> 这个原型不是「能不能生产」的问题，是「订单和垫资能不能同时撑住」的问题。设备商不会告诉你产能利用率，客户不会提前给你账期。
