# 品类目录库

每个文件对应一个普通人能接触的创业品类（决策 0025）。品类卡分两部分：**骨架**（结构字段，随技能分发，不含数字）与**检索缓存**（真实评估沉淀的 L1–L3 内容，标级别与复核日期）。

总表、组合规则与排除清单见 [00-catalog.md](./00-catalog.md)；位置在国标门类（`../industry-taxonomy.md`）之后、原型卡（`../archetypes/`）之前。

## 使用方式

体检时先把方向落进品类（口语识别词命中即算），取该卡必查项与档位；有缓存的品类再读缓存节：

- 缓存的 L1 内容（结构、节奏、死法）可直接支撑判断
- L2 只作范围参考，必须提示用户按当地实测
- L3 必须提示用户现场核实，不能替代官方查询
- 缓存不覆盖的形态（如 03 里的直播带货）按无缓存规则做结构推演

缓存超过六个月只当检索起点，超过十二个月视为无缓存。

## 新增约定

- 品类封顶 11 个，新增必须先写决策记录。
- 缓存只在真实评估后按 `_template.md` 的格式补录；不为覆盖而编数字。
- 骨架字段不得出现具体金额、客单、成功率。
- 卡片超过 120 行加「本文导航」；超过 200 行只修订不追加。
