# 检索工具缺失时的兜底

`offline-degradation.md` 处理「没有网络」。本文件处理另一种常见情况：**网络是通的，但会话里没有可用的搜索工具**。

两者看起来都是「搜不了」，但处理方式不同——前者只能降级，后者往往还能救，因为公开搜索端点不需要 API key。

**一句话分界：搜索工具报的是凭据错误（`no API key`、`401`、`未配置`），就进本文件；报的是超时、DNS 失败、连不上，就进 `offline-degradation.md`。** 误判成「离线」会让用户白等一个本来能答的问题；误判成「没工具」会让用户白试三个端点。两边都失败时，按 `offline-degradation.md` 带记录降级。

B 形态（单文件）也收录了本文件，所以「没工具」这条路径在只拿到一段文本的宿主上同样可用。

## 端点不排顺序，由你现场判断

本文件**不给端点排名**，只给候选池、判定方法和预算上限。选哪个、先试哪一组，由当前会话现场决定。

理由是端点的可用性取决于运行环境：同一条 URL，在一台机器上返回真实结果，在另一台机器上可能是连不上、验证页、空壳页或广告填充。写死顺序的唯一效果，是让后一种环境照着念一张不属于它的表。**顺序是判断的产物，不是判断的输入。**

## 怎么判断一个端点能不能用

**唯一判据：结果标题或摘要里，出现了查询的「判定性关键词」。** 不看状态码，不看域名能不能解析，不看页面能不能打开。

**判定性关键词是查这件事真正要的那个词，不是这个领域里最常见的那个词。** 查「小区门口摆摊许可规定」，判据是「摆摊 / 摊贩 / 许可 / 条例 / 管理」，不是「小区」。只命中「小区」，拿回来的是小区二手房信息——形式上过了关键词检查，实质完全离题。

查之前花十秒把查询拆开：

| 词 | 作用 | 算不算判据 |
| --- | --- | --- |
| 地点、领域词（赣州、小区、奶茶店） | 限定范围 | **不算**。太常见，任何沾边内容都有 |
| 判定词（许可、条例、规定、罚则、工资、租金） | 决定这个问题能不能答 | **算**。必须出现在标题或摘要里 |

一句话判据：**结果标题去掉地点词之后，跟要问的问题还沾边吗？** 不沾边就是失败。这条能挡住绝大多数「关键词命中但离题」。

失败要分类记，因为对用户的修复建议不同：

| 失败类型 | 表现 | 对用户意味着 |
| --- | --- | --- |
| 连不上 | `fetch failed`、超时、DNS 失败 | 这条网络到不了该域名 |
| 需跳转 | `cross-origin redirect`、跳到另一个域名 | 该 URL 要换成跳转后的目标域名 |
| 空壳页 | HTTP 200，但只有导航、热榜、标题，正文区无结果 | 结果靠脚本渲染，抓取工具拿不到 |
| 验证页 | HTTP 200，出现 Captcha、`JavaScript is required` | 端点对非浏览器请求设了人机验证 |
| 广告填充 | HTTP 200，有结果块但内容与查询无关 | 端点对非浏览器请求返回广告位 |
| 离题 | HTTP 200，结果块正常，但只命中地点/领域词，判定词全无 | 查询串或端点与任务不匹配，**先换查询串再换端点** |

六类都算**不可用**。后四行全是 200，所以**不能把状态码当成功**；最后一行尤其容易漏，因为它看起来完全正常。

判定固定三步：

1. **先测基线。** 打开一个几乎不可能失败的域名（如 `https://www.gov.cn/`）。打不开，说明是网络问题，直接转 `offline-degradation.md`，不要再试端点。
2. **按基线选组。** 基线能开、境外端点连不上，就是国内网络，从国内组开始；两组都能开，两组都可以试，但仍是**一次一个**。
3. **发一条检索计划里的查询，数关键词。** 标题或摘要里出现判定性关键词才算可用；只有页头、热榜、导航里出现，算空壳页；只有地点词命中、判定词全无，算**离题**，按失败处理并换端点。

## 一次失败只说明这一次，不要往上推广

**这是本文件最容易犯的错**，2026-10-30 实跑时真实发生过两次：某次查询返回了二手房，被判定成「必应不可用」；必应不可用又被说成「国内组不可用」。实际换到微信端点、换一条查询串，同一台机器、同一条网络上拿到了 1,000 条完全对口的政策结果。

三级失败，三个不同的处理动作。**跳级就等于把一个可修的问题报废掉。**

| 失败发生在 | 只说明什么 | 该做什么 | 不该做什么 |
| --- | --- | --- | --- |
| 一次查询结果离题 | 这条**查询串**对当前端点不合适 | 换查询串再试；或按任务类型换端点 | 说「这个端点坏了」 |
| 一个端点不可用 | 这个**端点**在这条网络/这个查询类型上不行 | 换同组下一个端点 | 说「这一组都不能用」 |
| 一整组端点全不可用 | 这个**任务类型**在这条网络上缺入口 | 转官方站点直连，或交用户查 | 说「没网了」，或直接封顶信息不足 |

硬规则三条：

1. **换端点之前，先换一次查询串。** 离题多半是查询写得太宽或词太泛，不是端点坏。同一查询在两个端点都离题，才判「这个任务类型搜不到」。
2. **一组里没用完的端点，不许替它们下结论。** 试了必应不满意就说「这组不行」，等于把没试过的端点也判了死刑。
3. **「不可用」必须带查询条件。** 写「必应对中文长查询的意图理解弱」，不写「必应不可用」。前者能用，后者会让下一个人直接跳过它。

同一条纪律也适用于实测记录：那是**某台机器、某条网络、某组查询**的现场结果，不是端点评级。换环境重测，不要照抄结论。

## 候选池：国内可达组

适合只能访问中国大陆网络的宿主：国内办公网络、内网代理、或境外域名被整体限制的环境。

| 端点 | URL 形态 | 能用时的样子 | 已知坑 |
| --- | --- | --- | --- |
| 微信搜一搜（搜狗镜像） | `https://weixin.sogou.com/weixin?type=2&query={query}` | 标题命中判定词，附公众号名称（多为政务号、综合执法号） | 链接是 `/link?url=...&token=...` 跳转；**结果是公众号转述，只当线索**；只覆盖公众号内容 |
| 必应国内版 | `https://cn.bing.com/search?q={query}` | 标题带站点域名、摘要带日期 | 主域名 `www.bing.com` 会 302 到这里，抓取工具常不跟随跨域跳转，必须直连 cn；**中文长查询意图弱，容易只命中地点词而返回无关结果**；页尾可能有「部分结果未予显示」 |

**两个端点不是备胎关系，是分工关系。按任务类型选，不按成败排队：**

| 要查什么 | 先进哪个 | 理由 |
| --- | --- | --- |
| 政策、办事条件、行业管理规定 | **微信** | 地方政务号发一手解读与全文转述，中文政务语境命中率高。2026-10-30 同一台机器实测：必应对这类查询返回二手房，微信返回 1,000 条对口政策 |
| 找部门官网域名、平台帮助页 | **必应** | 覆盖面广，擅长定位「谁管这事」；拿到域名后转「官方站点直连」 |
| 招聘薪资、租金行情 | 两个都可试 | 拿到的都是摘要，只当范围参考 |

微信结果**不能直接进判断**：它是转述，摘要只交出线索，原文要打开跳转后的页面并核对发布方与日期；政策条款最终仍要落到官方网站原文。

## 候选池：境外组

适合能访问境外域名的宿主。**不要把它当默认起点**：在国内网络里试境外端点，等于把预算花在证明自己到不了。

| 端点 | URL 形态 | 能用时的样子 | 已知坑 |
| --- | --- | --- | --- |
| DuckDuckGo HTML | `https://html.duckduckgo.com/html/?q={query}` | `result__a` 标题配 `result__snippet` 摘要 | 需完整浏览器头 + Cookie 处理，漏了会拿到 202 挑战页；`lite.` 与主域名同源同限制 |
| Brave | `https://search.brave.com/search?q={query}` | 结果量大 | 页面约 170 KB，结构随版本变 |
| Mojeek | `https://www.mojeek.com/search?q={query}` | 结果页 | 对非浏览器请求可能给 Captcha |
| Ecosia | `https://www.ecosia.org/search?q={query}` | 结果页 | 实际 302 到 bing，等于绕回必应 |
| Yahoo | `https://search.yahoo.com/search?p={query}` | 结果页 | 国内网络常见不可达 |

SearXNG 只给**自建实例**用：环境里存在 `OPENCLAW_WEB_SEARCH_SEARXNG_BASE_URL` 且实测可用时才用；变量不存在是正常情况，不要去找。

## 官方站点直连：不用搜也能到

**不属于搜索端点，但最该先想到。** 政策条款、处罚标准、办理条件这类必查项，只要知道去哪个部门，直接打开即可，不需要先搜到入口：

| 查什么 | 直接打开哪里 |
| --- | --- |
| 国家层面政策原文 | `https://www.gov.cn/`，政策文件库按关键词查 |
| 地方政策与办事指南 | 省政府、市政府、人社局 / 市场监管局子站 |
| 平台规则、佣金、入驻门槛 | 平台官方帮助中心 |
| 企业登记事项 | 国家企业信用信息公示系统 |

这条通道不依赖任何搜索引擎的抓取策略，比任何端点都稳。**检索计划里凡是能落到具体部门的项，都不该排进端点兜底。**

## 实测记录（2026-10-30，中国大陆网络）

同一天、同一台机器、同一条网络的完整结果，供判断时对照。**这是记录，不是标准**——换一台机器要重测，也不要拿它给端点评级。

**第一组查询（工资类，判定词「工资」）**

| 端点 | 结果 |
| --- | --- |
| `cn.bing.com` | 真实中文结果，标题与站点域名都对得上查询 |
| `weixin.sogou.com` | 823 条公众号结果，含地方政务号（赣州发布、赣州广播电视台） |
| `www.gov.cn` | 正常打开，基线可达 |

**第二组查询（政策类，判定词「摆摊 / 摊贩 / 许可 / 管理规定」）**

这一组的价值在于：**同一条网络上，两个端点给出完全相反的质量**，说明选端点要看任务类型。

| 查询串 | 端点 | 结果 | 判定 |
| --- | --- | --- | --- |
| `小区门口 摆摊 许可 规定` | `cn.bing.com` | 200，16,000 条，前 10 条全是阿克苏二手房、安居客、房天下 | **离题**：只命中「小区」 |
| `摊贩 管理规定 城市` | `weixin.sogou.com` | 200，约 1,000 条，全部为城管/综合执法政务号发布的摊贩管理政策 | **可用** |

微信这一组命中的是《百色市右江区城区流动摊贩管理办法》《福安市流动食品摊贩经营行为通告》《陕西省食品小作坊小餐饮及摊贩管理条例》这类一手政策转述，正是 H3 合规前置要的东西。

**不可用，及其原因**

| 端点 | 失败类型 | 实测 |
| --- | --- | --- |
| `www.bing.com` | 需跳转 | 302 到 `cn.bing.com`，抓取工具直接报错 |
| `www.sogou.com/web` | 空壳页 | 200，正文区无结果 |
| `www.baidu.com/s` | 空壳页 | 200，正文区无结果 |
| `so.toutiao.com` | 空壳页 | 200，只有导航与热榜，结果靠脚本渲染 |
| Mojeek | 验证页 | 200，Captcha 挑战 |
| DuckDuckGo（`html.` / 主域名 / `lite.`） | 连不上 | 全部 `fetch failed` |
| Brave | 连不上 | `fetch failed` |
| Yahoo | 连不上 | `fetch failed` |
| Ecosia | 需跳转 | 302 到 bing |

**从记录里读出的四条判断：**

1. **「国内可达」不等于「能拿到结果」。** 百度、搜狗网页、头条都是 200 且国内可达，结果区却是空的。只按域名归属选端点，会选中这三个。
2. **境外端点在这条网络上全灭，不是它们坏了。** 换一条能访问境外的网络，它们仍是有效候选——失败记录写的是环境，不是端点。
3. **`www.bing.com` 要用 `cn.bing.com`。** 主域名会跳转，抓取工具多数不跟随跨域跳转，第一跳就报错。
4. **同一台机器上，必应能用但会离题，微信能用且对口。** 所以「必应返回二手房」不能证明「必应不可用」，更不能证明「国内组不可用」。这次误判真实发生过，记在这里当反例。

## 调用纪律

这仍然是检索，**一样受 `runtime-loop.md` 的预算约束**（线上必查项 × 2，上限 12；成本类单独 2 个）。换端点不等于可以多搜。

五条要求：

1. **先测基线，再选组。** 基线打不开就不是端点问题，按 `offline-degradation.md` 处理，别再试。
2. **必须验证结果相关。** 拿到 HTML 不算成功，要看标题或摘要里有没有**判定性关键词**。实测里五个失败的端点全是 HTTP 200，另有一次 200 且命中了地点词、但内容完全不相关。
3. **离题先换查询串，不要先换端点。** 见「一次失败只说明这一次」。同一条查询打三个端点，拿回来的是三份一样的空。
4. **端点结果只当线索。** 摘要用来发现线索，原文用来做依据（`research-protocol.md`）。政策条款必须再打开原文。
5. **记下失败类型，不是只记「失败」。** 降级提示要写清是连不上、需跳转、空壳、验证页、广告填充还是离题——用户据此才知道该配密钥、换网络、换查询，还是该去问当地部门。

## 做不到的事

公开端点能搜到，但**打开原文可能失败**：

- 招聘平台（BOSS 直聘、智联、58 同城）多为 JS 渲染或反爬，摘要能拿到，薪资详情页常打不开
- 政策原文页一般能打开，优先用政府域名
- 商铺租金的挂牌信息可拿到区间，但成交价拿不到

遇到打不开原文的，按 `offline-degradation.md` 的「半离线」处理：**政策类按「没查到」算，不能用摘要当依据**。

这一点尤其重要：招聘摘要里写「3-6K」可以当区间线索，但不能当「当地实发工资」写进 H2 的分母。
