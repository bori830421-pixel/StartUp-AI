# 出资与权责结构：一个人干还是几个人干

模式分叉决定「用哪套成本结构算钱」，这一步决定「钱是谁的、谁说了算、退的时候怎么算」。两者位置相同，都在体检之前，都只改分项不改原型。

## 为什么单独一步

七种原型按「收入靠什么」划分。合伙不改变任何一条收入来源，它改的是所有权和责任结构，所以**不进原型表，另立一步**。

插在模式分叉之后、体检之前，理由和模式分叉相同：它同样改变分项输入。位置放错会出两种错——放在分叉之前，会用「一个人干」的成本结构去算几个人干的账；放在体检之后，分数已经算完，改分项等于推翻结论重来。

判断顺序不变：先按钱筛原型（`capital-bands.md`），再分经营模式（`pattern-fork.md`），再定出资与权责结构，最后进七维体检。

## 该不该合伙

先做这一刀，因为它能挡在合同之前。绝大多数「我想找个人合伙」的真实缺口只有三种，每种都有**不占股的解法**：

| 真实缺口 | 不占股的解法 | 什么时候才必须合伙 |
| --- | --- | --- |
| 缺钱 | 借款（写清利息与还款）、只给分红权不占股、客户预付、供应商账期 | 对方愿意一起承担亏损，并接受这笔钱被锁住 |
| 缺人 | 雇、兼职、外包、按项目分成、底薪加提成 | 你付不起市场工资，只能拿长期收益换 |
| 缺资源 | 按单返点、介绍费、渠道分成、资源置换 | 资源方要持续投入，并参与决策 |

三种缺口都能用一次性交易解决。合伙是长期关系：**只有当对方同时要「长期投入 + 共担亏损 + 参与决策」时，合伙才成立。** 少一条，就有更轻的解法。

一个反例值得单独说：为了「绑定」而给股份。绑定用分成、长约、期权都能做，这三样可逆；股份不可逆。用不可逆的手段解决可逆的需求，是新手最常见的一次性错误。

判断结论只允许三档：不必合伙（给替代解法）、可以合伙（进下面的折股与条款）、已经合伙了（走存量入口）。

## 出什么

四类出资，各有各的坑。**非现金出资必须能验收**，不能验收的写成「里程碑换股」，不要一次性给。

| 形式 | 要算清什么 | 最常见的坑 |
| --- | --- | --- |
| 现金 | 金额、到账日、打进哪个账户、转账备注写什么 | 备注不写用途，事后「是借款还是投资」两说 |
| 人力 | 全职还是兼职、每周多少小时、承诺期多长、不到位怎么处理 | 口头「我全职干」没有期限，三个月后人不见了，股还在 |
| 资源 | 折成可验证的交付物和时间表：几个客户、哪条渠道、哪张牌照、什么时候到位 | 「我有资源」折走两成股，一个客户也没带来 |
| 知识产权 | 配方、品牌、软著、账号归谁；许可使用还是转让 | 配方是其中一方的，散伙后另一方立刻不能卖 |

一条纪律：资源股按里程碑分期给，不按「我认识谁」一次性给。

## 主体形态

新手默认以为「注册了公司就是有限责任」。这句话只在一种形态下成立。

| 形态 | 对外责任 | 登记与决策特征 | 常见适用 |
| --- | --- | --- | --- |
| 个体工商户 | 经营者个人承担，无限责任 | 登记在一个人名下，没有「股」这个概念 | 一个人干、规模小 |
| 个人独资企业 | 投资人无限责任 | 一个人，可开发票 | 一个人干、需要开票 |
| 普通合伙企业 | 合伙人对企业债务承担无限连带责任 | 合伙协议是核心文件 | 专业服务类 |
| 有限责任公司 | 股东以认缴出资为限 | 章程 + 股东会 + 执行董事/经理 | 两人以上长期合作，最常见 |
| 有限合伙 | 普通合伙人无限、有限合伙人以出资为限 | 合伙协议约定管理权与出资 | 出资人与管理人分离 |

三条要讲清（属常识层，具体适用按当地登记机关与执业律师确认）：

1. **「有限责任」有条件。** 个体户、个人独资、普通合伙都不是有限责任，经营债务可能牵连个人和家庭财产。
2. **个体户没有「股」。** 登记的是经营者一个人，出资人之间只能靠协议约定，对外不产生股东身份；分钱靠协议，查账也靠协议。
3. **法定代表人对外代表主体，是风险位不是荣誉位。** 谁当，谁就要承担对应的对外责任与限高风险。

## 什么时候定主体形式

这一处最容易被排错顺序。三条约束：

1. **不能等体检之后才问。** 主体形式直接进 S1、H3、S4 三项：个体户无限责任、有限公司以认缴为限，S1 的算法就不同；H3 要登记主体、要章程、许可还要看主体资质；S4 要看退出难度。用错假设算完再重算，等于白跑一轮。
2. **也不需要先注册。** 体检时按「拟采用的形式」算，不要求已经登记。H3 写成条件句：「按有限公司算，餐饮需要食品经营许可，周期约若干周；若注册个体户，许可口径与责任承担都不同。」
3. **注册放在放行之后。** 注册有费用、有周期，注销比注册更麻烦。没放行就注册，等于替一个还没验证的方向先付了沉没成本。

顺序因此是：引导盘点第 10 题粗判有没有别人 → 这一步定形式并给对比 → 体检按拟定形式算分 → 放行后才去登记。

还有一处措辞要改：**「你是独资个体还是合伙制」不是一个二选一。**「合伙」说的是关系（几个人一起干），「个体户 / 有限公司」说的是形式，两个维度可以交叉——三个合伙人注册一家有限公司是最常见的做法，一个人也可以注册有限公司。所以问法是两问：先说有没有别人一起出钱，再问注册成五种形式里的哪一种。

## 改哪四个分项

分叉之后必须重算，不能只改结论。

| 分项 | 怎么改 |
| --- | --- |
| S1 资金匹配 | 按「你自己的钱 + 你可能被追的责任」算，不按总盘算。凑够了不等于你的风险变小 |
| H2 现金流断点 | 合伙人的出资是一次性进账，不是收入，**不进分母**；但分红义务与追加出资义务会加大月度流出 |
| H3 合规前置 | 要登记主体、要有章程或协议、要开对公户；许可类还要看登记主体是否具备资质，周期比个体经营长 |
| S4 失败可逆性 | 原口径只算设备转卖与押金退还。合伙要补一个子项：**出资能不能退出、按什么价退出**；补不上按 1 分算 |

S4 的补充最容易被漏掉：设备能卖、押金能退，但一笔出资卡在没有退出条款的结构里，回收率仍然是零。

## 两条入口

| 入口 | 前提 | 做什么 | 出口 |
| --- | --- | --- | --- |
| 增量 | 还没签、钱还没出 | 该不该合伙 → 出什么、分多少 → 条款与退出怎么写 | 照常进七维体检，过闸门才陪跑 |
| 存量 | 已签、已出资、已开业 | 现状清点 → 按不可逆程度排风险 → 先补哪一条 → 止损上限 | 补救顺序，不构成放行，不进入陪跑 |

两条入口共用同一套条款清单（`partnership-terms.md`）与红旗清单（`partnership-redflags.md`），区别只在出口：一个给判断，一个给顺序。

存量入口的存在理由：对已经出资的人跑体检没有意义（H2 已是既成事实），而把他挡在门外，他会自己乱来。所以给的不是判断，是「先补哪一条」和「最多再亏多少」。

## 不做什么

- 不判断条款是否有效、可撤销或显失公平，不解释法条。
- 默认不给合同、章程正文，只给条款清单、核对动作与提问清单；客户坚持要文本时按 `legal-boundary.md` 的分界线降级，不直接拒绝，也不整份代拟。
- 不替用户谈判、不代拟给对方的法律文件。
- 涉及登记、税务、诉讼与债务承担，指向当地登记机关、税务部门和执业律师，并提示带齐材料再问。

条款怎么核、红旗怎么排、股比怎么算，分别见 `partnership-terms.md`、`partnership-redflags.md`、`equity-math.md`。
