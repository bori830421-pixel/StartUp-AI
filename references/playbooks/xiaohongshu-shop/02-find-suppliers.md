# 02 寻找供货渠道

按 `../../task-playbook-template.md` 执行。本任务只建立候选名单与询价信息，不代表供应商已通过核验，也不替用户联系或下单。

## 目标与前置条件

- 已通过启动闸门，且[选品假设](./01-product-hypotheses.md)选出一个待验证商品。
- 用户已明确可接受的样品费、首批采购上限、期望交期和可接受的最低质量条件。
- 若预算、库存或现金流条件与闸门结论冲突，暂停，不以更大的订单“验证”。

## 当次检索

| 要查什么 | 去哪个官方页面 | 查到什么算够 | 查不到怎么办 |
| --- | --- | --- | --- |
| 供应商主体登记信息 | 国家企业信用信息公示系统 → 企业信息查询入口 | 能查到主体名称、统一社会信用代码、登记状态与经营范围，且与报价单、合同抬头一致 | 名称模糊或存在多个近似主体 → 要求供应商提供营业执照，按代码精确检索；查不到 → 该渠道标「主体未核」，不进入询价比较 |
| 食品生产经营许可 | 属地市场监管部门的食品经营许可公示 / 查询入口（入口以经营地为准） | 能回答“该供应商是否持有与所供商品对应的许可、许可主体与供货主体是否同一” | 属地入口不明 → 请用户在属地市场监管部门官网查询并回传截图；仍无 → 该项挂起，不采购需许可商品 |
| 批发平台资质展示位 | 1688 等批发平台的店铺资质 / 证照展示区（位置以当次打开为准） | 能指出该店铺是否展示营业执照与许可，并记录展示的证照名称与主体 | 只有「已认证」一类标识 → 记为该平台内部认证，回到前两行用官方系统核；无展示 → 标「未展示」，不作可信依据 |
| 品牌授权链 | 品牌权利人官方渠道；国家知识产权局商标网上查询 | 能回答“该品牌由谁持有、供应商的授权是否可追溯到权利人” | 权利人无公开渠道 → 要求提供授权书，并核对授权主体与商标注册人是否一致；不一致 → 淘汰 |

入口核对日期：2026-11-02 ｜ 入口结构以当次打开为准。只核对入口是否存在，不核对内容；入口本身变了由运行时重查。

供应商、平台招商页、招商广告的自述按利益相关信息处理；报价和“爆款”“稳定出单”等宣传只能作为待核线索。记录仍需写清平台、查询词、页面、日期、报价口径和是否含税 / 运费。

## 操作

1. 列出少量可比较的渠道。区分生产方、品牌方、经销商、批发平台与代发服务，不把“平台入驻”误当成质量背书。
2. 用同一询价清单联系渠道：具体 SKU / 规格、样品条件、单价阶梯、起订量、现货与补货周期、发货地、包装与贴标、退换 / 瑕疵处理、发票、授权 / 检测文件、付款主体与合同主体。
3. 把每个报价拆成金额、单位、有效期、含税口径、运费与附加条件。对方没有书面确认的字段标“未知”。
4. 先争取样品或小额可逆验证。付款前确认收款主体、合同主体、退款和质量责任；所有付款由用户决定并执行。

## 检查点与停止条件

- **继续**：有可比较的书面报价，并能进入主体、样品和履约核验。
- **补证**：关键信息只是口头承诺；要求补书面条款或样品，不填补猜测值。
- **淘汰 / 停止**：拒绝提供基本主体信息或样品条件，要求未经核验的大额预付，收款人与合同主体不一致且无法解释，或出现疑似假货 / 侵权风险。

请用户带回书面报价与沟通记录，再进入[核验供应条件](./03-verify-supplier.md)。
