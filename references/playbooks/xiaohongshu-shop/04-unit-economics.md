# 04 单品经济账

按 `../../task-playbook-template.md` 执行。目标是算清用户当前经营方案下每笔订单可能留下多少现金贡献；不预测销量或承诺盈利。

## 目标与前置条件

- 已有供应商书面报价；平台店铺类型、商品类目、销售方式和用户实际结算口径明确。
- 用户提供预算上限、验证周期、可接受损失和自己的时间成本处理方式。
- 若费用或规则在商家后台才可见，由用户提供页面数值与截图 / 字段名；助手不假称能查看后台。

## 当次检索与数据

- 平台扣费、保证金、活动费用、带货佣金、发货 / 售后要求按当次官方规则与店铺后台核实。
- 采购价、运费、包装、退货、补发和仓储用书面报价、样品试算或用户记录。网络区间只能作线索。
- 标明每个数字来自用户记录、官方原文、第三方区间、估算或假设；无法核实的项留空并做敏感性说明。

## 操作

1. 分开记录标价、消费者实付、平台补贴、卖家承担优惠和后台结算收入，避免把不同口径混成“收入”。
2. 计算单笔贡献：

   `单笔贡献 = 商家实际结算收入 − 货品成本 − 进货运费分摊 − 包材 − 出库运费 − 平台扣费 − 带货 / 投放费用 − 预计售后与补发成本`

3. 另列固定成本、库存占款、样品和一次性投入、用户工时及税费待核项。现金贡献与包含工时的全成本结果分开，不把老板劳动记为“免费”。
4. 只用已有证据设置低 / 中 / 高情景；不要自己补转化率、退货率或月销量。缺项时指出哪一项会改变结论，并算出该项的保本边界。
5. 在投入前与用户约定最低可接受贡献、最大损失和停止日期。计算结果若改变现金流或预计首笔收入时间，回到体检重判 H2。

## 检查点与停止条件

- **继续**：关键数据有用户记录或可核依据，按用户预设的最低要求仍有可行的验证空间。
- **补证**：结论对某个未知费用高度敏感；先向平台或供应方核实，不用平均值填空。
- **停止 / 回体检**：保本条件超出用户预算、单笔贡献为负且无可验证的改进变量，或 H2 可能不过。

输出算式、敏感项与一项下一步数据收集动作；不把利润测算等同于实际收益。
