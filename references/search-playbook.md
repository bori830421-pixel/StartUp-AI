# 检索剧本

本文件把「要查什么」翻译成**可直接执行的查询串**。粒度要求：拿到就能搜，不需要再想怎么措辞。

配合 `runtime-loop.md` 使用：先跑循环，用本文件的模板生成检索计划。

## 四类通用查询公式

| 类型 | 公式 | 期望质量 |
| --- | --- | --- |
| 政策类 | `<事项> <动作> 条件 材料 <城市>` | 高，优先官方域 |
| 成本类 | `<类目> 成本 占比 房租 人工` | 低，只取结构不取数字 |
| 价格类 | `<服务或商品> 价格 <城市> 多少钱` | 最低，必须实测 |
| 负面类 | `<品牌> 加盟 投诉 亏损 纠纷` | 中，用于尽调交叉验证 |

政策类必须带城市名。只写「中国」搜到的是全国口径，落地会错。

## 七个原型的查询模板

### 一、卖时间

| 要查什么 | 查询串 | 站点 |
| --- | --- | --- |
| 从业资格 | `<城市> 网约车 驾驶员证 办理 条件 材料` | 本地交通运输局 |
| 车辆准入 | `<城市> 网约车 车辆 准入 轴距 排量 车龄` | 本地交通运输局 |
| 营运险 | `网约车 营运险 费用 比 家用险 贵多少` | 保险机构、媒体 |
| 平台抽成 | `<平台名> 司机 抽成 比例 规则` | 平台官方 |

### 二、卖货·轻库存

| 要查什么 | 查询串 | 站点 |
| --- | --- | --- |
| 摆摊是否允许 | `<城市> 流动摊贩 管理 规定 摆摊` | 城管、政府门户 |
| 摊位备案 | `食品摊贩 备案 办理 <城市>` | 市场监管 |
| 健康证 | `健康证 办理 <城市> 费用 周期` | 疾控中心 |
| 品类季节性 | `<品类> 销售 旺季 淡季 月份` | 行业媒体 |

同类摊位的实际销量**不搜**，只能现场数。这是本原型最重要的动作。

### 三、卖货·重库存

| 要查什么 | 查询串 | 站点 |
| --- | --- | --- |
| 租金水平 | `<城市> <商圈名> 商铺 租金 每平米 每月` | 商铺中介平台 |
| 周转速度 | `<品类> 库存 周转 天数 动销` | 行业媒体 |
| 前置许可 | `<品类> 经营许可 办理 条件` | 市场监管 |
| 商圈空置率 | 实地看（不搜） | — |

### 四、卖技能与服务

| 要查什么 | 查询串 | 站点 |
| --- | --- | --- |
| 当地市场价 | `<服务> <城市> 价格 多少钱 一次 每小时` | 本地生活平台 |
| 资质要求 | `<服务> 需要 什么 资质 证书 许可` | 政府门户 |
| 用工责任 | `员工制 中介制 区别 社保 工伤 责任` | 法规、律师解读 |
| 平台规则 | `<平台名> 服务商 入驻 抽成 结算` | 平台官方 |

当地市场价的最优做法是假装客户打 5 家电话问价，检索只用来确认量级。

### 六、买系统·加盟

| 要查什么 | 查询串 | 站点 |
| --- | --- | --- |
| 备案 | `商业特许经营 备案 查询 <品牌名>` | 商务部特许经营信息管理平台 |
| 披露义务 | `商业特许经营信息披露管理办法 全文` | 商务部 |

## 站点限定

| 领域 | 优先域 |
| --- | --- |
| 全国政策法规 | gov.cn、各部委官网 |
| 市场监管（执照、食品、生产许可） | samr.gov.cn |
| 生态环境（环评） | mee.gov.cn |
| 商务（特许经营、家政） | mofcom.gov.cn |
| 交通（网约车） | 本地交通运输局 |
| 平台规则 | 各平台官方帮助中心 |

检索时可用 `site:` 限定，例如 `site:gov.cn 食品经营许可 条件`。

## 会搜到什么垃圾

见到这些，直接降级或跳过：

| 类型 | 识别特征 | 处理 |
| --- | --- | --- |
| 招商加盟平台 | 域名或标题含「加盟」「招商」「投资多少钱」「利润分析」 | D 类，只当线索 |
| 自媒体统计 | 「揭秘」「内幕」「我统计了 100 家」 | L4，不进判断 |
| 问答与文库 | 无作者、无日期、内容拼凑 | E 类，只当线索 |
| 过时解读 | 引用已废止的法规或旧版办法 | 必须回溯现行原文 |
| 培训课程页 | 结尾引导加微信、领资料、报名 | D 类，跳过 |
| 品牌软文 | 通篇正面、无缺点、有联系方式 | D 类，只当线索 |

## 地区变量的处理

政策类查询必须落到城市。三条规则：

1. 直辖市写市名，如「上海市」
2. 省辖市写「省 + 市」，避免与同名区县混淆
3. 查不到市级口径时，降级到省级，并明确标注「按省级口径，市级需向当地部门确认」

不要用别的省市的例子代替本地。小餐饮备案、摆摊管理、网约车准入，各地差异都很大。

## 一个反例

差的检索计划：

> 查一下摆摊卖小吃的成本和政策。

好的检索计划：

| # | 查询串 | 判据 |
| --- | --- | --- |
| 1 | `<城市> 流动摊贩 管理规定 摆摊` | 找到官方文件即算查到 |
| 2 | `食品摊贩 备案 办理 <城市>` | 找到办理条件与周期 |
| 3 | `健康证 办理 <城市> 费用` | 找到费用与周期 |
| 4 | `<品类> 销售 旺季 淡季` | 找到季节规律 |
| 5 | 现场数 3 个点位（不搜） | 拿到同类摊日销量 |

差别在于：前者搜完不知道算不算查到了，后者每条都有判据。
