# 合伙条款：十二条必查与六个反事实提问

给「协议是合伙人起草的、看不懂、已经签了」这类场景用的核对方法。目标是**找出缺什么**，不是解释条款的法律效力。

## 为什么不是读条款

新手读不懂条款，不是语文问题，是缺参照物：不知道「正常应该写成什么样」，就无法判断手里这份少了什么。

所以不逐条读，而是**带着问题去文件里找答案**。找得到，抄下来；找不到，记一条缺口。缺口清单比读后感有用得多，也是去见律师时最省钱的材料。

一个经验判断：朋友之间起草的协议，通常把「出多少钱、分多少红」写得很细，把「怎么退、谁说了算、不干活怎么办」写得极简甚至不写。**风险几乎全部落在没写的那部分。**

## 先找六个数字五个动作

拿到文件先做这件事，五分钟能定位到关键位置，不必从头读。

| 六个数字 | 说明 |
| --- | --- |
| 出资金额与到账日 | 谁出多少、哪天到账、打到哪个账户 |
| 股权或份额比例 | 写的是百分比，还是「按出资比例」这种指代 |
| 分红比例 | 和股权比例是不是同一个数 |
| 退出价格公式 | 有公式，还是「协商确定」「按原价」 |
| 违约金金额 | 有没有具体数字，还是只写「承担违约责任」 |
| 争议解决地 | 哪个法院或哪个仲裁机构 |

| 五个动作 | 说明 |
| --- | --- |
| 谁签字生效 | 一个人签还是全体签，缺一个签是否有效 |
| 谁管账户 | 网银、U 盾、支付账号在谁手上 |
| 谁能改章程 | 改章程要多少比例同意 |
| 谁能让人停职或退出 | 有没有除名、停职、强制转让的条款 |
| 怎么解散清算 | 谁提议、多少比例通过、剩余财产怎么分 |

六个数字是「钱怎么算」，五个动作是「权在谁手」。两组都空着的条款，基本等于没约定。

## 十二条必查

逐条对照，缺一条记一条。右列不是法律后果，是**没有它的时候，现实里通常发生什么**。

| # | 条款 | 要写清什么 | 缺了会怎样 |
| --- | --- | --- | --- |
| 1 | 出资与到账 | 谁出多少、到账日、收款账户、逾期怎么办 | 「说好一起投」变成一个人垫，垫的人没有凭证 |
| 2 | 出资形式与作价 | 设备、场地、技术、客户资源怎么折价、谁定、能不能复核 | 一方拿旧设备按新价折股，另一方无法反驳 |
| 3 | 三种权利分开写 | 分红权、表决权、剩余财产分配权可以不同比例 | 以为三成就是三件事都三成，实际只能分钱不能说话 |
| 4 | 人力承诺 | 全职还是兼职、每周多少小时、承诺期、不履行怎么处理 | 「我全职干」没有期限，人走了股还在 |
| 5 | 决策规则 | 哪些事必须一致同意、哪些事谁定、僵局怎么破 | 对半分又没有僵局条款，一件事谈崩整家店停摆 |
| 6 | 钱章证谁管 | 账户与 U 盾、公章、营业执照原件、谁签字生效 | 一方全控，另一方连账都看不到 |
| 7 | 分红政策 | 什么时候分、分多少、留多少、亏损年度怎么处理 | 「有利润就分」变成永远不分，或分光没留流动资金 |
| 8 | 追加出资与稀释 | 谁出、不出怎么算、能不能强制、按什么价 | 交房租时才谈增资，不出钱的一方被动稀释或被迫借高息 |
| 9 | 退出与回购 | 四种触发（主动、过错、丧失能力、死亡）、定价公式、支付节奏、未成熟部分怎么处理 | 想走走不了；或者只能按原始出资退，干两年一分不多 |
| 10 | 竞业与归属 | 散伙后能不能做同类、客户名单归谁、配方与账号归谁 | 走的人在隔壁开一家，客户全带走 |
| 11 | 违约与争议 | 违约金怎么算、先协商还是直接诉、去哪个法院或仲裁机构 | 出事才发现要跑到对方城市打官司 |
| 12 | 主体与登记 | 章程是否个性化、谁是法定代表人、有没有代持、配偶是否签字 | 协议写了章程没写，对外只认登记；代持在融资和诉讼时最麻烦 |

十二项里最容易被跳过的是第 9 项和第 4 项：**退出**和**不干活**。这两项在关系好的时候谈最尴尬，在关系坏的时候最贵。

## 反事实六问

不用法律知识，用六个「如果」去文件里找答案。每一问找不到，就是一条缺口；六问里空三条以上，这份约定的退出机制基本不存在。

| 如果…… | 它在逼出哪一条 | 找不到的后果 |
| --- | --- | --- |
| 我干了三个月不想干了 | 第 9 条：退出触发与回购定价 | 想走走不了，或者只能拿回原始出资 |
| 我生病半年不能来 | 第 4、9 条：人力承诺的暂停与丧失能力退出 | 分红照拿被指责，或者股被单方收回 |
| 他不再投钱，还要我继续垫 | 第 8 条：追加出资义务与性质（出资还是借款） | 垫的钱变成「自愿投入」，要不回来 |
| 客户是我带来的，散伙后归谁 | 第 10 条：客户资源归属与竞业 | 人走了客户留下，或者反过来被说成挖客户 |
| 要增资我拿不出钱 | 第 8 条：稀释规则与优先认缴权 | 一夜之间从三成变一成，且无法反对 |
| 我离婚，或他去世 | 第 12 条：配偶权益与继承 | 伙伴突然变成对方的配偶或继承人 |

这六问还有一个用法：**谈之前先问对方**。对方愿不愿意正面回答，比条款写得多漂亮更能说明这段合伙关系的质量。

## 章程与协议的关系

三句常识（具体适用以当地登记机关与执业律师确认为准）：

1. **对内看协议，对外看登记。** 你们之间怎么约定是一回事，登记机关和第三方看到的是另一回事。
2. **工商模板章程通常只有法定必备条款**，你谈的分红、退出、竞业大多不在里面。协议写得再细，章程里没有对应表述，就会出现两份文件各说各话。
3. **两份文件冲突时，先找有没有「以本协议为准」这类表述**，再带着两份文件去问律师。不要自己判断哪份优先。

代持要单独提一句：登记股东与实际出资人不是同一个人时，实际出资人主张权利靠的是证据链（出资凭证、代持约定、参与经营的记录），不是「大家都知道我是老板」。

## 不做什么

- 不判断条款是否有效、可撤销或显失公平。
- 默认不给合同、章程正文：需要文本时先去当地市场监管部门的示范文本入口取，再回来核对缺哪几条。
- 客户坚持要我们拟时，不直接拒绝，按 `legal-boundary.md` 降级：只写当事人意志类条款（出资、比例、分红、分工、退出定价），法律条款（违约、管辖、担保、对赌、竞业、代持）留「待律师落笔」，并带强制声明。章程只做范本填空指引，不自拟。
- 不说「签了就得认」，也不说「这条肯定无效」。两种说法都是在替你下结论。
- 缺的是证据而不是条款时（例如只有转账没有备注），先补证据，再谈条款。
