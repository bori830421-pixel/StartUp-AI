# 合同与章程审阅：只看事实，不下判断

客户把一份协议拍照发过来，说「你帮我看看有没有坑」。这是合伙分支里最高频的请求，也比「帮我拟一份」更危险：**拟是写什么，看是判断对不对**，而判断对不对只有执业律师能做。

但完全不给答案也不成立。客户要的其实不是法律意见，是**知道自己该怕什么**。这件事不需要法律知识，只需要三样东西：对照、核对、清点。

## 一、为什么「看」比「拟」危险

拟稿的风险是「写错了被当成约定」；审阅的风险是**「说对了但被当成保证」**。

客户听到「这条没问题」，记住的是「可以签」，不是「这一条我看不出问题」。等他后来吃亏，回想的不是你没看全，是你说过没问题。

所以审阅的第一条纪律不是少说，是**把话说在事实层**：写没写、对不对得上、有没有、缺几条。事实错了可以修正，判断错了没法收回。

## 二、三层输出，都不需要法律判断

### 第一层：不对称清单（最有用，也最容易被跳过）

对方起草的协议，坑通常不是条款违法，是**只约束一边**。这是纯文本对照，客观可查：

| 查什么 | 常见形态 |
| --- | --- |
| 违约金 | 写了你违约怎么赔，没写他违约怎么赔 |
| 出资期限 | 你的到账日期写死，他的写「另行商定」 |
| 退出 | 写了你想退怎么处理，没写他想退 |
| 竞业 | 限制你不做同行，不限制他 |
| 决策 | 写重大事项需他同意，没列你需要他同意的事 |
| 分红 | 写「按约定分配」，但约定在哪没有 |

这一层的说法是：「**这五处只写了他能要求你的，没写你能要求他的。**」不是「这几条对你不利」——后者是判断，前者是事实。

### 第二层：缺口清单

按 `partnership-terms.md` 的 12 条必查逐条标：有 / 没有 / 写了但空。**「没有」是事实，「写了但对你不利」是判断**，只报前者。

再加反事实六问：拿「我干三个月不想干了 / 我生病半年 / 他不再投钱还要我垫 / 客户是我带来的散伙后归谁 / 增资我拿不出钱 / 我离婚或他去世」去文件里找答案。找不到就是缺口。

### 第三层：数字核对

这一层常被忽略，但错误率最高，而且完全不需要法律知识：

- 比例加起来是不是 100%
- 出资额和比例对不对得上（出 30% 的钱，写固定分红 5 万/年，两者必有一个是错的）
- 日期矛不矛盾（签约日早于主体成立日、认缴期限早于开业日）
- 金额大小写是否一致
- 同一个人在不同条款里的身份是否一致（一会儿是「合伙人」一会儿是「员工」）

**算不平的地方，往往就是双方当时没谈拢、用一句话糊过去的地方。** 这类地方比违法条款更常见，也更容易在散伙时爆。

## 三、「能不能签」怎么答

这个问题一定会被问，而且不能躲。但不能答「能」或「不能」——那是法律结论。答**后果**：

> 这三条不补，出事时你手上没有任何书面依据：退出怎么算、他不再出钱怎么办、你带来的客户散伙后归谁。补不补你定，但你得知道不补意味着什么。

差别在于：前者是替他决定，后者是把决定权和他的代价一起交回去。**给后果不是给结论**——后果是事实推演，结论是效力判断。

如果客户继续追问「你就说有没有问题」，只回一句：**「我能告诉你缺什么，不能告诉你算不算数。这句话得律师说，而且他得看原件。」**

## 四、六个形态信号，见到就转律师

下面六条不需要判断内容，只看形态，但每一条都意味着「这份文件现在不能签」：

1. 有空白项——金额、日期、比例留空，等签的时候再填
2. 只有一份，没有副本
3. 签字页单独一页，没有骑缝章或骑缝签字
4. 出现「另行约定」「另行协商」，但没有对应附件
5. 出现你不认识的法律术语：对赌、回购、代持、质押、让与担保、优先清算权
6. 你要为对方的债务提供担保，或以个人名义为经营主体担保

第 6 条最容易被忽略，也最致命：它把「有限责任」直接打穿，一次签字可能抵掉整个主体形式的选择。

## 五、章程只看三处

不用通读。章程大多是范本填空，格式条款没有信息量，只有三处值得看：

| 看哪里 | 看什么 | 为什么 |
| --- | --- | --- |
| 表决比例 | 哪些事项需要多少比例通过 | 决定你能不能推动任何事，也决定对方能不能否掉你 |
| 出资期限 | 认缴出资什么时候到位 | 到期没到位，责任在你，不在登记机关 |
| 有无「以协议为准」 | 章程与协议冲突时按哪份 | 没有这句，你谈的分红、退出在章程里等于不存在 |

**第三处是判断「你的约定有没有进章程」的唯一入口**：翻遍章程找不到你谈过的分红方式和退出规则，就说明它们只活在协议里，而协议对外不公示。

## 六、开场与收尾的固定说法

开场先说清做了什么、没做什么，一句话：

> 我按「写了什么、缺什么、数字对不对」给你过一遍，不判断条款算不算数——那是律师的事。你要的是一份该问什么的清单，还是一份能拿去给律师的材料？

收尾给三件事，不给结论：**缺口清单、数字对不上的地方、见律师的三个问题**。

顺手一句留痕：让客户把原件或完整照片留着，别只发截图。**审阅截图和审阅原件，能看出的东西差一个量级**——骑缝、页边、手写添加、附件顺序，都只在原件上看得出来。
