# 引导盘点：8 道选择题

新手答不出开放式问题，但答得出选择题。不要问「你的风险承受度是多少」，要问「这笔钱亏光会不会影响生活」。

## 1. 你要的是哪一种

- A 一份能替代工资的现金流
- B 时间自由，能自己安排
- C 做成一件属于自己的事
- D 先学一门生意，赚不赚钱次要

影响：A → 现金流断点权重最高；B → 时间匹配权重最高；C → 可逆性权重最高；D → 优先低成本、可学习的方向。

## 2. 每周能稳定投入几小时

- A 5 小时以内
- B 5–10 小时
- C 10–20 小时
- D 20 小时以上（接近全职）

## 3. 可用启动资金

- A 0 元
- B 1 万以内
- C 1–5 万
- D 5–20 万
- E 20 万以上

## 4. 这笔钱全部亏光，会影响生活吗

- A 不影响
- B 有压力，但能承受
- C 会影响基本生活

影响：选 C 时，任何需要投入超过可用资金 30% 的方向都要在判断里明确标出。

## 5. 没有收入的情况下能撑几个月

- A 不到 1 个月
- B 1–3 个月
- C 3–6 个月
- D 6 个月以上

影响：直接进现金流断点判定。可撑月数必须大于等于预计首笔收入月数加 1。

## 6. 你已有的技能（多选）

- 销售与沟通
- 手工或制作
- 拍摄剪辑与内容
- 编程或技术
- 设计与排版
- 教学或咨询
- 供应链或采购
- 驾驶或本地跑动
- 其他（请写）

影响：进能力缺口。关键动作里缺 3 个以上，基本做不动。

## 7. 你认识的人里有（多选）

- 目标客户
- 同行或从业者
- 供应商或渠道
- 都没有

影响：进客户可达判定。选「都没有」时，该项不能直接判通过，需要靠后续动作补。

## 8. 所在城市，或打算服务的区域

开放填写，只要求一个地名。

影响：决定合规门槛、客户密度和本地渠道。地区缺失时，合规前置只能标待核实，不能判通过。

## 使用规则

- 一次最多问 4 题，分两轮，避免新手被 8 题吓退。
- 用户已经给出某些答案（例如「我预算 5 万」），跳过对应题目。
- 用户不愿答某题时，按最保守值代入，并在输出里标明「该项按保守假设处理」。
- 8 题答案直接映射到七维体检，不额外增加提问。
