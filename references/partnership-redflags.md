# 合伙红旗清单

红旗不等于违法。多数红旗是**合法但不公平**，或者**合法但你没看懂**。清单的作用是排序：哪一条不解决会死人，哪一条可以忍。

## 怎么用这份清单

三个等级按「不可逆程度」排，不按严重程度排。一级的共性是：一旦发生，钱、责任或身份收不回来；二级是能谈判、但必须落纸；三级是提醒，知道就行。

每条只给「为什么危险 + 先做什么」。判断是否合法、是否可撤销，是执业律师的事，不是这份清单的事。

## 一级 签字前必须解决

| 红旗 | 为什么危险 | 先做什么 |
| --- | --- | --- |
| 无限连带责任落在你个人 | 普通合伙、个体户、个人独资都不是有限责任，经营债务可能牵连个人与家庭财产 | 先确认主体形态，再决定要不要签；需要有限责任就换形态，不是靠协议约定 |
| 你是实际出资人，登记在别人名下 | 对外你不是股东，查账、分红、退出都只能靠证据链与协议 | 补书面代持约定 + 保留出资凭证 + 留存参与经营的记录；能改登记就改登记 |
| 你当法定代表人，但钱和章不在你手上 | 对外代表主体，风险在你；对内又没有控制权 | 要么拿到钱章的控制或监督权，要么换人当 |
| 个人为合伙债务担保，或对赌回购由个人承担 | 责任从「出资额为限」变成「全部身家」 | 把担保范围、期限、上限写成具体数字，写不出上限就不签 |
| 对半分或三方均分，没有僵局条款 | 任何一件事谈崩都可能让经营停摆，且没有出口 | 加僵局条款：一方买断、第三方调解、轮流决策或解散，四选一写死 |
| 认缴金额远高于你能承担 | 认缴不是不用管，特定情形下会被要求提前履行 | 按实际能拿出的钱认缴，不为了「显得有实力」写大数 |
| 公章、账户、执照由一方独占且无监督 | 你无法核实经营与资金，也无法阻止对外担保 | 约定共管或定期提供流水；拒绝提供流水本身就是信号 |
| 没有退出条款，或退出价格由对方单方决定 | 想走时你没有定价权，谈判地位为零 | 先补定价公式（四选一见 `equity-math.md`），再谈其他 |

## 二级 能谈但要写进协议

| 红旗 | 缺了会怎样 |
| --- | --- |
| 分红政策没写 | 「有利润就分」变成永远不分；或者分光不留流动资金，下个月交不起房租 |
| 竞业与客户归属没写 | 散伙后对方在隔壁开同类店，客户跟着走，你无法主张 |
| 知识产权归属没写 | 配方、品牌、账号归谁不清，散伙时一方立刻不能继续经营 |
| 增资与优先认缴权没写 | 需要追加投入时，你不出钱就被稀释，出钱又没有优先权 |
| 关联交易没约束 | 合伙人让自己的另一家公司供货，价格由他定 |
| 一票否决权范围过宽 | 一方可以否决一切，等于另一方没有决策权 |
| 配偶未签字 | 婚后取得的份额涉及共同财产，处置时可能出现第三方主张 |

## 三级 提醒与自查

| 事项 | 自查动作 |
| --- | --- |
| 税务 | 分红、股权转让各有对应纳税义务；签之前问清由谁承担、怎么申报 |
| 劳动关系 | 合伙人是否同时是员工、社保由谁交、工资与分红是否分开 |
| 决策记录 | 股东会决议、微信里的关键确认、转账备注，都要留存；口头一致等于没有 |
| 婚姻与继承 | 份额的继承与配偶权益，提前在协议里写处理方式，比事后争更便宜 |

## 六个常见认知盲区

**一、以为股权比例就是一个数。** 分红权、表决权、剩余财产分配权是三件事，可以不同比例。只写「占三成」，等于三件事都按三成默认，而你想要的可能只是分红。

**二、以为章程和协议是一回事。** 对内看协议，对外看登记。工商模板章程通常不含你谈的那些条款，协议写得再细，章程里没有对应表述就会各说各话。

**三、以为注册了公司就有限责任。** 个体户、个人独资、普通合伙都不是。形态选错，协议写得再漂亮也挡不住个人责任。

**四、把法定代表人当荣誉。** 它是对外代表主体的位置，伴随对应的责任与限制消费风险。不当家的人当法定代表人，是风险错配。

**五、以为「大家都知道我是老板」就够了。** 代持情形下，实际出资人主张权利靠证据链：出资凭证、代持约定、参与经营的记录。

**六、忽略婚姻与继承。** 婚后取得的份额属于共同财产范围，处置时可能触发配偶主张；份额继承也可能让合伙关系突然多出一个陌生人。

## 看到红旗之后的顺序

1. **先停手。** 没签的先不签，没打款的先不打款。已经签了的不要再追加投入——追加会让沉没成本变成新成本。
2. **按不可逆排序。** 责任类（连带、担保、法定代表人）排最前，身份类（代持、登记）其次，条款类（退出、竞业）再次。
3. **带三个问题去见律师**，别让咨询费花在介绍背景上：
   - 按现在这份文件，最坏情况是什么，会不会牵连到个人和家庭财产？
   - 出资性质、退出定价、查账权这三条要补成什么样才站得住？
   - 补签要谁签字、要不要办变更登记，先后顺序是什么？
4. **补签或退出。** 补签优先于翻脸：一份把三件事写清的补充确认，比一场没有证据的争执便宜得多。补签谈不成，再评估退出与止损。
