# StartUp-AI

一个可配合 AI 使用的创业指南技能。输入关键词、方向或预算限制，输出经过假设标注、可小步验证的创业行动方案，需要时整理成 PPT/PDF 内容。

## 当前状态

文档框架阶段。已有规则、能力边界、验收场景和 5 个行为样例；没有实现代码、数据存储或外部集成。

## 目录

| 路径 | 内容 |
| --- | --- |
| `SKILL.md` | 技能入口：使用流程与必须遵守的规则 |
| `AGENTS.md` | 项目协作与维护规则 |
| `docs/` | 架构地图、能力索引、验证指南、决策记录 |
| `references/` | 输出模板：初筛、启动计划、零资金页、PPT 页序 |
| `examples/` | 行为样例，用于验证规则可执行 |

## 怎么用

1. 读 `SKILL.md` 了解 8 步流程和硬约束。
2. 看 `examples/` 了解实际输出形态，每个样例对应一个验收场景。
3. 需要组织结构时查 `references/output-templates.md`。

## 设计原则

- 区分事实、估算、假设、待核实四类信息，不把预测包装成事实。
- 不虚构市场规模、成本、法规或成功率；动态信息注明来源与日期。
- 零启动资金方案必须披露隐性成本，不把「无现金」写成「无成本」。
- 结论是条件式的，每个方案都附继续或停止指标。

## 边界

本技能提供结构化分析与规划辅助，不替代投资、法律、税务或监管判断。涉及这些领域时，提示用户按所在地向专业人士确认。
