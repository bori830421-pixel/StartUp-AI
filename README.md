# StartUp-AI

一个面向创业新手的 AI 技能。你说出想做的方向和手里的钱，它先判断「现在该不该开始」；判断可以做，才进入分阶段陪跑，帮你把第一笔钱挣到。

## 它解决什么问题

新手最缺的不是更多的分析，而是一句能信的判断。

但「你成功的概率有多大」这个问题没有任何诚实的方式能回答。所以本技能不预测结果，只检查条件：启动这件事需要的东西，你现在满足几项。

```text
阶段一 体检 → 闸门 → 阶段二 陪跑
```

体检不过，就没有陪跑。这是设计上的硬约束，不是建议。

## 怎么用

1. 读 `SKILL.md` 了解两阶段结构和闸门规则。
2. 看 `examples/06` 和 `examples/07`，对照「不建议启动」与「放行」两种输出形态的差别。
3. 需要具体口径时查 `references/` 下的三份文件。

## 判断分三档

| 结果 | 条件 | 后续 |
| --- | --- | --- |
| 放行 | 三个硬门槛全过，软约束最多 1 项偏弱 | 直接进入 P1 接触 |
| 有条件放行 | 硬门槛全过，软约束 2 项及以上偏弱 | 先补短板，复核通过再进 P1 |
| 不建议启动 | 任一硬门槛不过 | 给最小代价出口，不给陪跑 |

三个硬门槛是客户可达、现金流断点、合规前置。四个软约束是资金、时间、能力、可逆性，只用来排序和找短板，不求和——总分会把否决项稀释成可接受的扣分。

## 判断依据从哪来

不做「行业很大所以能做」这类推理。体检的依据分三层：

1. **结构**（来自行业档案卡）：成本比例、现金流节奏、哪一项刚性、通常怎么死
2. **实测**（来自用户）：客流、客单价、房租、生活开支
3. **核实**（来自官方）：证照要求、办理周期

行业数据按四级标注，级别决定它能不能进判断：

| 级别 | 内容 | 能否进判断 |
| --- | --- | --- |
| L1 结构级 | 成本结构比例、现金流节奏、常见死法 | 可以，标结构性判断 |
| L2 区间级 | 客单价、毛利、启动资金区间 | 只作范围参考，须标日期与口径 |
| L3 事实级 | 政策条款、证照要求、平台规则 | 必须现场核实，不替代官方查询 |
| L4 传闻级 | 自媒体统计、招商宣传、加盟广告 | 不能进判断，只能当线索 |

招商加盟平台、品牌方、培训机构的数据属于利益相关来源，一律打折。规则见 `data/source-grading.md`。

## 设计原则

- 区分事实、估算、假设、待核实四类信息，不把预测包装成事实。
- 不虚构市场规模、成本、法规或成功率；动态信息注明来源与日期。
- 判断必须挂在分项上。不给无依据的结论，也不给「都可以，看你」。
- 零启动资金方案必须披露隐性成本，不把「无现金」写成「无成本」。
- 陪跑一次只给一个阶段。新手看完完整计划会以为自己懂了，然后什么都不做。

## 边界

本技能提供结构化分析与规划辅助，不替代投资、法律、税务或监管判断。涉及这些领域时，提示用户按所在地向专业人士确认。
