# 验证记录

本目录存放「真实用户任务」的执行记录，用来把 `docs/capability-index.md` 里的能力从「规则已定义，已有样例」升到「规则已定义，已有样例，已验证」。

## 什么算一次验证

状态口径只认一件事：**样例在真实用户任务中复现过，且用户确认输出可用**。样例是维护者自己写的，复现过也不算；必须是外部用户带着自己的条件来，拿到输出后明确表示能据此做决定。

一次验证记录必须写清五件事：用户给的原始输入、实际输出了什么、用户怎么确认的、覆盖了哪些能力、**没有覆盖哪些**。最后一项不是免责声明，是防止后续有人把一次窄验证读成全面验证。

## 约束

- 记录只增不改。后续同一用户再次使用，新建编号记录，不覆盖旧结论。
- 不记录用户身份、联系方式或可回溯到个人的信息；城市与经营条件按用户原话保留，这是判断依据的一部分。
- 验证只对**当时那次输出**成立。同类方向再问，仍要从头跑检索与体检，不能凭这条记录放行。
- 记录里的数字保持不变，即使后来查到更新值——要更新的是新的评估，不是旧记录。
