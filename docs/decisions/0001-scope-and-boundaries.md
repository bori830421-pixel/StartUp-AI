# 决策记录 0001：项目范围与边界

- 状态：已采纳
- 日期：2026-10-28

## 背景

项目希望成为可配合 AI 使用的创业指南，输入可以从关键词或创业方向开始，也可以包含领域、预算和零启动资金限制；输出包括方向建议、启动框架，以及按需提供的 PPT/PDF。

## 决定

- 第一阶段交付项目规则和 Markdown 文档框架，技能以 `SKILL.md` 作为使用入口。
- 能力拆为需求收集、方向探索、可行性验证、启动规划和交付整理五个模块。
- 建议必须区分证据、估算、假设和待验证事项，并以小规模验证为主要行动方式。
- 零启动资金场景必须披露隐性成本和不可省略的资源条件。
- PPT/PDF 是按需交付形式；具体文件生成取决于可用工具。
- 当前不实现应用代码、用户数据存储、外部集成或自动化任务。

## 后果

后续扩展应优先补充能力规则和验证样例。若要引入代码、市场数据服务、用户档案或文件自动生成，需要再明确架构、数据处理边界和相应验证方案。
