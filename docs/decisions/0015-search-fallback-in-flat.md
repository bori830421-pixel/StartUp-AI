# 0015 检索兜底进单文件：先判「没工具」，再判「没网」

## 背景

2026-10-30 用 B 单文件在 DeepSeek 桌面端实跑 `install` 用例（小区门口摆摊卖烤肠，预算 3000）。宿主的搜索工具报 `DeepSeek search has no API key for "DEEPSEEK_API_KEY"`，模型按 flat 头部的降级声明直接宣布「连不上网」，交了一份「信息不足」的判断。

事后核对，同一台机器上：

- `references/search-fallback.md` 早已写好（7 个端点实测、请求头的坑、相关性验证），A 形态能读到，**B 形态读不到**；
- flat 第 679 行确实提了「按 `search-fallback.md` 试公开端点」，但 `build_flat.py` 只收 4 份 references，**这个引用在单文件里没有对应材料**；
- flat 头部那句「当前环境没有联网工具时，结论封顶在信息不足」是平级声明，与第 679 行直接冲突，模型只按头部走。

补齐材料后仍失败：改打 DuckDuckGo 与 Brave 两个端点都是 `fetch failed`，`pwsh` 也起不来（`0xC0000142`）。这暴露第二个缺口——**端点全失败时的落点没写**，降级提示里没有「试过什么、报什么错」，用户看到的是「AI 没试就放弃了」。

## 决定

1. `build_flat.py` 的 `PARTS` 加入 `references/search-fallback.md`，**排在 `offline-degradation.md` 之前**（先判没工具，再判没网）。收录清单从 4 份变 5 份。
2. flat 头部的平级降级声明改为**三档检索声明**：有工具直接用 → 工具报凭据错误先打公开端点（上限 3 个）→ 端点也失败才降级，且降级要带检索记录。保留「降级时封顶在信息不足」，但把它挂到第三档上。
3. `offline-degradation.md` 第一节从「三种搜不了」改为「五种」，把「凭据错误」列成独立一类，并补两张表：真离线与「端点全失败」的判定分叉；降级提示新增第五句（检索记录）。
4. `search-fallback.md` 新增「调用顺序与上限」：DuckDuckGo → Brave → 其它标记可用的端点，**上限 3 个，每个只试一条**；三个都失败立即转降级。
5. `examples/24-search-fallback.md` 补第六节「如果端点也全失败」，把这次的合体情况写成可判定的样例。
6. `SKILL.md` 第 6 步与「必须遵守」各加一条：先判「没网」还是「没工具」。版本升到 0.5.0。

## 理由

**为什么加文件而不是把兜底塞进头部。** 头部是模型最先读、也最容易只读的部分，它适合放判断顺序，不适合放端点的 URL、请求头与解析正则。把平级声明改成有条件的顺序，头部就只剩「先做什么」，细节留在被收录的文件里。

**为什么 order 是 1 不是 2。** `offline-degradation.md` 的入口是「没网」，`search-fallback.md` 的入口是「没工具」。两条路的前置判断只有一条：能不能打开任意外部 URL。把没工具那份放前面，模型读到「离线」字样之前会先看到「别急着判离线」。

**为什么设 3 个端点的上限。** 兜底不是重试，是换路。三个引擎打同一份查询拿回来的还是同一份「没有网」，只是把预算花在证明自己没网上。上限写死在文档里，与 `runtime-loop.md` 的「判定后只重试一次」是同一条约束的两面。

**为什么降级提示要带检索记录。** 结论不变，但用户对原因的判断完全变了：从「AI 不灵」变成「我这台机器要配密钥」。这是把一次失败变成一条可执行的修复线索，代价只有一句。

**为什么不在离线降级里写死「去哪个设置页配密钥」。** 宿主各异，写死就是第二种真相。第五句只要求「一句修复线索」，具体页面由当前宿主自己说。

## 后果

- **flat 体积上涨**：42.0 KB / 17,857 字 → 54.8 KB / 24,541 字，按约 1.6 字/token 估，token 从约 12,600 涨到约 15,300。8k 宿主早已装不下（154%），32k 宿主占用从 38.5% 升到约 48%。可接受，因为这个文件的用途就是「只能塞一段文本」的宿主，而检索能力是它的核心卖点之一。
- **改了 `references/` 就必须重跑 `build_flat.py`**，否则 `--check` 报过期。本次改动把「flat 引用了一份没收录的文件」这类问题也交给了 `--check` 的字节比对，只要源与产物不同就红。
- **A/C 形态不变**：C 形态的 `resources` 本就全量枚举 `references/*.md`，新规则自动可见；A 形态直接读文件。
- **计口径要同步**：`INSTALL.md`、`hosts/plain-prompt.md`、`hosts/README.md`、`docs/capability-index.md`、`docs/verification-guide.md` 里所有「四份 / 5 份」的表述一并改成五份。
