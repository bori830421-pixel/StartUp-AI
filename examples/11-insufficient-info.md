# 样例 11：体检信息不足（不判结论）

覆盖能力：启动条件体检、闸门判定、行业档案引用
对应验收场景：`docs/verification-guide.md` 阶段一「体检信息不足」

本例演示第三种状态：用户不是「测了不够」，是「还没测」。这时不给判断结论，也不给阶段任务，只给补测动作。

同时固定一条分界：H3 的「待核实」和这里的「信息不足」不是一回事。两者都表现为「不知道答案」，但处理方式相反——前者按不通过处理，后者不判。

## 输入

> 我 35 岁，在成都，之前在电子厂做质检，现在待业。想在小区门口开个面馆，存款 18 万，能全职做。附近有几家在转让，但我还没数过客流，也没去问过要办什么证。

## 一、盘点结果

| 题目 | 回答 |
| --- | --- |
| 你要的是哪一种 | 现金流。待业，需要收入替代工资，现金流断点权重最高 |
| 每周可投入 | 20 小时以上，按全职 60 小时估 |
| 可用资金 | 18 万，全部积蓄 |
| 亏光是否影响生活 | 会影响基本生活 |
| 无收入能撑几个月 | 月生活支出 5,000（房租 2,000、生活 3,000） |
| 已有技能 | 手工或制作（会做家常菜）、其他（工厂质检，有品控与流程意识） |
| 认识的人里有 | 都没有 |
| 地区 | 成都 |

## 二、先确认这是不是信息不足

用户说了两次「不知道」，但这两次的性质不同，处理方式也不同：

| 用户的话 | 性质 | 处理 |
| --- | --- | --- |
| 「我没数过客流」 | 信息不足 | 客观上能测，只是没测 → 给补测动作，不判 |
| 「我说不出 10 个客户」 | 不通过 | 已经能判断：手上没有客户 → 判不通过 |
| 「我问过同行，说不用办证」 | 仍是信息不足 | 非官方渠道不构成查询，等同于没查 |
| 「我查了，这个区说要现场核查，那个区说备案就行」 | 待核实 | 已查但口径不明 → 按不通过处理 |

判据只有一句：**查询动作有没有发生**，不是知不知道答案。

本例两项都是第一种。

## 三、能算的照常算

### 硬门槛

| 门槛 | 判定 | 依据 |
| --- | --- | --- |
| H1 客户可达 | 信息不足 | 没数过客流，也没定铺位。不是「没有客户」，是「还没去看」 |
| H2 现金流断点 | 通过 | 最低启动现金约 9 万：押金 1.5、装修 2.5、设备 1.5、首批备货 0.5、3 个月固定成本 3。18 万付完剩 9 万，月固定支出 1 万（房租 5,000、生活 5,000），可撑 9 个月；爬坡期 3 个月加首笔正现金流约 4 个月，9 ≥ 5 |
| H3 合规前置 | 信息不足 | 没查过。社区餐饮通常要食品经营许可，部分地区 50 平方米以下可走小餐饮备案，但成都的具体办法没查 |

### 软约束

| 维度 | 分数 | 依据 |
| --- | --- | --- |
| S1 资金匹配 | 3 | 18 万对 9 万，覆盖 2 倍 |
| S2 时间匹配 | 3 | 待业可全职，每周可投入 60 小时以上；面馆按熟练后 60 小时估，覆盖 |
| S3 能力缺口 | 0 | 关键动作 5 个：选址、产品标准化、采购、门店运营、营销。会做家常菜不等于能做商用出品；质检经验对品控有帮助，但不等于门店运营。缺口 4 个，其中选址与产品标准化都难外包 |
| S4 失败可逆性 | 1 | 装修 2.5 万基本沉没，押金受租约锁定，设备折价大 |

软约束先算完不是白算：S3 和 S4 两项 ≤1 分，这个结果在补测后仍然成立，会直接决定补测通过后的档位。

## 四、结论：不判，先补测

> **这次不给判断。H1 和 H3 两项不是「不过」，是「还没测」。**

三件不做的事：

1. 不说「可以启动」，也不说「不建议启动」
2. 不给 P1 到 P4 任何阶段任务
3. 不给预算表和行动计划

原因：现在无论说哪一边，都是拿没测过的东西当测过了。说放行，用户会直接去签铺子；说不建议，会把一个资金和时间都够的方向误杀。

H2 已经通过，这一项不用补。

## 五、补测动作

### H1 客户可达（3 天）

**做什么**：从转让的店里选 3 个候选铺位，每个连续 3 天蹲点。3 个铺位可并行，实际 3 天完成。

**什么时候数**：午市 11:30–13:00、晚市 17:30–19:30，各数一次。

**数什么**：进入周边 500 米内同类面店和快餐店的**人数**，不是路过的人数。同时抄 3 家店的菜单价格，记客单价区间。

**怎么判**：先算自己的保本线，再看这个区域撑不撑得起。

```text
保本流水 = 月固定成本 ÷ (1 − 变动成本率)
         = 10,000 ÷ (1 − 0.48)
         ≈ 19,200 元/月
日流水   ≈ 640 元
```

- 月固定成本 1 万：房租 5,000 加生活 5,000，先不雇人
- 变动成本率 48%：按档案卡取食材 32% + 营销 10% + 杂费 6%

客单价按蹲点实测（档案卡标了「无可靠公开数据，必须实测」）。若取 20 元，日需 32 单。

**判断标准**：3 家同类店的日均进店人次取平均。平均明显高于 32 单，说明这个区域的同类店能活，H1 判通过；平均低于 32 单，说明这个位置撑不起保本线，H1 判不通过。

这条线的每个数字都能自己算出来，不依赖任何报告，也不依赖招商平台的宣传口径。

### H3 合规前置（3 天）

**做什么**：查成都市（具体到区）市场监管局公开信息，然后打一次电话或去一趟市场监管所。

**问三件事**：

1. 小区门口 30–50 平方米的面馆，要食品经营许可，还是可以走小餐饮备案
2. 现场核查看什么（布局、流程、设施），最容易卡在哪
3. 从提交到拿证要多久

**判断标准**：无需前置许可，或周期 ≤ 准备期，判通过；周期超过准备期，判不通过。

档案卡已收录两条依据：申请食品经营许可须先取得营业执照（市场监管总局令第 78 号第十条）；小餐饮备案是地方制度，不是全国统一。所以这一项必须问成都本地，不能套用安徽或广元的例子。

### 一件不用等的事

S3 的短板和补测无关，现在就能动：找一家面馆打两周零工，或去一家生意好的店连吃一周并记录出品与出餐节奏。这不属于补测，也不构成阶段任务——它只是把「缺口 4 个」变成「缺口 3 个」。

## 六、补测后会出现哪几种结果

| H1 | H3 | 结论 |
| --- | --- | --- |
| 通过 | 通过 | 有条件放行：硬门槛全过，但 S3 为 0 分、S4 为 1 分，两项偏弱，先补这两项再复核 |
| 通过 | 不通过 | 不建议启动，卡在合规：许可周期超过准备期，先解决资质再回来 |
| 不通过 | 通过 | 不建议启动，卡在客户可达：这个位置撑不起保本线，换位置重测，不要硬上 |
| 不通过 | 不通过 | 不建议启动，两处都卡 |

第一行要特别注意：**即使两项都通过，也不是放行**。S3 和 S4 已经算出来了，两项都 ≤1 分，按判定规则属于有条件放行。补测只决定「能不能往下走」，不决定「现在能不能开始」。

## 七、这次体检里哪些不是档案卡给的

- 房租 5,000、装修 2.5 万、设备 1.5 万、押金 1.5 万：按成都小区门口小面馆的结构做的估算，不是询价结果。定铺位前必须用实际报价替换。
- 生活支出 5,000：用户自述。
- 变动成本率 48%：档案卡 L2，来自综合餐饮口径，不是面馆专门口径。定品类后按实际重算。
- 客单价：档案卡标「无可靠公开数据」，必须蹲点实测。
- 食品经营许可与小餐饮备案：档案卡 L3，有官方原文，但成都的具体办法没查——这正是 H3 要补的。

## 自检

- [x] 两项硬门槛判的是「信息不足」，没有当成不通过，也没有当成通过
- [x] 没有给判断结论，也没有给阶段任务、预算表或行动计划
- [x] 补测动作写清了做什么、做几天、记录什么、怎么判
- [x] 说明了补测后可能出现的两种结果及各自对应的结论（本例列了四种组合）
- [x] 其余维度照常算完，没有因为两项信息不足让整份体检作废
- [x] 保本线是算出来的，不是引用外部数据；客单价明确要求实测
- [x] L3 内容提示了必须问成都本地，没有套用其他地区例子
- [x] 区分了「信息不足」与「待核实」，没有把没查过的当查过了
