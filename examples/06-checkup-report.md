# 样例 06：体检报告与三档判定

覆盖能力：启动条件体检、闸门判定
对应验收场景：`docs/verification-guide.md` 第 6–9 行

本例演示最需要克制的场景：用户想做一件在现有条件下做不成的事。判断是不建议启动，输出必须点明卡在哪，并给最小代价出口，不给陪跑计划。

## 输入

> 我 32 岁，在成都有份稳定工作，想加盟开一家奶茶店。预算 5 万，每周能投入 15 小时，没做过餐饮。

## 一、盘点结果

| 题目 | 回答 |
| --- | --- |
| 你要的是哪一种 | 现金流，想多一份收入（有全职工作，属副业） |
| 每周可投入 | 10–20 小时，取 15 |
| 可用资金 | 5 万 |
| 资金带 | B4（3–10 万）。能碰固定摊位与小店；方向是成熟品牌加盟，实际要 B6（30 万以上），差两档 |
| 亏光是否影响生活 | 有压力，但能承受 |
| 无收入能撑几个月 | 生活靠工资，不受影响；项目资金 5 万 |
| 已有技能 | 销售与沟通 |
| 认识的人里有 | 都没有 |
| 地区 | 成都 |

## 二、七维体检

### 硬门槛

| 门槛 | 判定 | 依据 |
| --- | --- | --- |
| H1 客户可达 | 不通过 | 只能说出「年轻人、学生、上班族」，说不出具体位置、日均客流和周边同类店数量 |
| H2 现金流断点 | 不通过 | 最低启动现金估算 15–25 万（加盟费、装修、设备、押金、首批原料），可用资金 5 万，开业前即耗尽，可撑月数小于 1 |
| H3 合规前置 | 通过 | 需食品经营许可证，周期约 1–2 个月，短于准备期 |

说明：15–25 万是按常见加盟品牌结构做的估算，不是市场数据。要确认必须拿 3 个具体品牌的报价单核对，见下方待核实。

### 软约束

| 维度 | 分数 | 依据 |
| --- | --- | --- |
| S1 资金匹配 | 0 | 5 万对 15–25 万，缺口超过 50% |
| S2 时间匹配 | 0 | 门店需全职看店加排班，每周 60 小时以上，可投入 15 小时 |
| S3 能力缺口 | 0 | 关键动作缺选址、产品、供应链、门店运营、营销共 5 个 |
| S4 失败可逆性 | 1 | 装修和加盟费基本无法回收，设备折价大 |

## 三、判断

> **当前条件下不建议启动。卡在两处：资金差 3 倍以上，且没有可验证的客流依据。**
>
> 5 万开不了加盟奶茶店，这不是风险问题，是算术问题。即使凑够钱，每周 15 小时也支撑不了一家需要全天营业的门店。

硬门槛：H1 不通过、H2 不通过、H3 通过。

## 四、最小代价出口

不建议启动不等于这件事不能碰。如果你还想验证，只做这一件事：

**动作**：不加盟、不租店。用两个周末，在你看中的位置做一次快闪测试——借一家已有店铺的门口或夜市摊位，卖 100 杯自制饮品。

**判断标准**：单时段卖出 40 杯以上，且有人第二次来买，说明这个位置有真实需求，再谈开店；卖不到 20 杯，停止。

**损失上限**：500 元物料加两个周末。不签任何合同，不付任何押金。

这个动作不解决资金缺口，只回答一个问题：这个位置到底有没有人要买。这个问题没答案之前，凑钱开店是把风险放大而不是缩小。

## 五、如果你仍然决定要做

那不是启动，是试错。三条底线：

1. 损失上限提前写死，不超过 5 万，且不动用生活储备
2. 不签超过 1 年的租约，不付超过 1 个月的押金
3. 加盟合同签字前，找律师看一遍退出条款和费用结构

## 六、待核实

| 事项 | 去哪查 |
| --- | --- |
| 目标品牌的实际加盟费、保证金、设备费、原料加价率 | 直接向 3 个品牌索取书面报价单，不接受口头报价 |
| 该品牌现有门店的真实流水 | 找 2 家非本地的加盟店实地看，问日均杯量 |
| 成都餐饮服务许可与消防要求 | 当地市场监管部门公开信息 |
| 商铺租约的转让费与押金惯例 | 当地中介与已开店商户 |

## 自检

- [x] 判断点明了卡在哪一项，不是笼统的「风险较大」
- [x] 没有把估算当成市场数据，估算口径写清并要求核对
- [x] 不建议启动时给了最小代价出口（一个动作、一个标准、一个损失上限）
- [x] 没有给陪跑计划、阶段任务或预算表
- [x] 用户坚持要做时，给了三条底线而非直接服从
